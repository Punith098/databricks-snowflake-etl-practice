# Databricks Snowflake ETL Practice

This repository is for practicing:
- Connecting GitHub with Databricks
- Running queries in Snowflake (proto tables → transform tables)
- SQL query optimization
- Identifying and avoiding ETL anti-patterns
- Pull Requests in Databricks Repos and Zflow

## Repository Structure

- `notebooks/` → Databricks notebooks
- `sql_scripts/` → SQL scripts for proto & transform tables
- `etl_patterns/` → Good and bad ETL practices
- `databricks/` → PR workflow & Zflow integration
- `docs/` → Setup guide

## How to Use

1. Clone this repo to Databricks.
2. Follow setup instructions in `docs/setup_guide.md`.
3. Run SQL scripts in Snowflake via Databricks SQL.
4. Commit changes and raise Pull Requests for review.
